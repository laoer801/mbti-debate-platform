前言

我是这个产品的设计者。这份文档不用来"介绍"，而用来"交代"——把产品能做什么、这些功能带来了什么影响与创新、它对辩论和学习究竟改变了什么，以及每一个功能键该怎么用，一次性讲清楚。

最后一章是按键手册，覆盖从顶部导航到 PK 房间里的每一个按钮。你可以把它当作上手用的操作说明，也可以当作验收用的功能清单。

一、产品功能总结

1.1 一句话定义

思辩星球是一个以 MBTI 人格为身份、以 AI 为辩手与裁判、以实时辩论为核心交互的在线辩论平台——把"观点交锋"从静态问答升级为可参与、可评分、可沉淀的动态内容场。

二、功能带来的影响与创新

2.1 功能创新总览

功能传统做法我们的做法带来的影响
AI 对手没有对手就不辩AI 三档难度永远在线辩论不再依赖"凑人"
逐句发言整段一次性输出按句连发、1.1 秒一条从"读稿"变成"对话"
场景玩法一个模板套所有话题四场景各有模式与目标同一引擎产出四种气质
实时对战异步、易跑题三阶段 + 服务器权威判定交锋有章法、结果可信
七维评分凭感觉判断谁强七维量化 + 训练计划进步有了可测的标尺
知识库通用资料导入你自己的知乎内容AI 用你的素材与你对练
AI 裁判人工评判成本高自动评分 + 战报办赛与复盘的成本骤降
语音输入只能打字语音实时转文字 + HTTPS 解锁表达门槛降到"开口就行"

2.2 四点关键创新

创新一 · 发言节奏引擎：把"像不像人"做成可调参数

行业普遍把 AI 回复整段倾倒，机器感由此暴露。我们把回复拆句、按节奏释放，观点表达完整后才交还回合，并允许"AI 主动开场 / 用户请 AI 继续说"两种打断。这一项改变的不是内容，而是"在场感"。

创新二 · 三档 AI 对手：把训练强度做成可选

初级陪新手、中级有套路、大师会学你的打法。难度不再是"提示词换个说法"，而是模型档位、温度、回复长度、是否学习用户风格的组合，形成可感知的阶梯。

创新三 · 场景玩法引擎：把"玩法"做成可扩展的配置

场景 = 模式 + 目标 + 话题池 + 玩法提示。四要素一变，玩法就变。这意味着未来新增"模拟法庭""新闻发布会""心理咨询"等场景，不需要改内核。

创新四 · 三源知识引擎：把"你的内容"变成交战素材

本地文档 + 云端共享 + 知乎导入三源合一。用户把自己的知乎回答和收藏导入后，AI 下一场就能引用其论点来反驳他——学习材料与训练对手从此是同一套。

2.3 功能影响速览

影响维度具体表现
对用户表达门槛降低、参与动机变强、成长可见
对内容每场辩论自动产出结构化观点，可传播、可沉淀
对社群观点广场承接辩论结果，形成讨论闭环
对生态与知乎双向供给话题与内容
对成本AI 裁判替代人工评判，办赛与复盘成本大幅下降

三、对辩论与学习的影响

3.1 对辩论的影响

  • 把"找人"变成"开局"——辩论最大的隐性成本是凑齐对手；AI 对手让任何人在任何时间都能开辩。
  • 把"吵架"变成"结构化交锋"——立论 / 自由辩论 / 总结三阶段，让辩论有章法、可复盘。
  • 把"我觉得我赢了"变成"我逻辑 78、论据 45"——七维评分把主观感受变成可改进的清单。
  • 把"一次性的"变成"可沉淀的"——每场自动生成战报，观点可发布，交锋留下痕迹。
  • 把"人机"边界抹平——AI 以影子用户身份与真人同轨，人机混战的体验完全一致。

3.2 对学习的影响

  • 从"输入"到"输出"——学习真正的闭环在输出；辩论强制你把学过的东西当场用出来。
  • 从"看别人辩"到"被诊断"——七维评分 + 7 天训练计划，直接告诉你怎么练、练哪个维度。
  • 从"通用资料"到"我的资料"——导入知乎收藏与回答，学习材料与训练对手同为"你自己的思想"。
  • 从"哑巴表达"到"开口练习"——语音输入把表达门槛降到"敢开口"，练的是真正说得出来的能力。
  • 顺带的知识补充——审题报告、资料包与每日新闻，让每一场辩论都顺带学到新东西。

3.3 传统方式 vs 本产品

维度传统辩论 / 学习思辩星球
对手来源临时凑人，不稳定AI 三档永远在线
反馈速度事后回忆、无人点评当场七维评分 + 战报
练习强度靠自觉，无阶梯三档难度 + 训练计划
素材来源通用资料你自己的文档与知乎内容
表达方式写为主说、写皆可（含语音）
结果沉淀散落在聊天记录里结构化报告 + 观点广场

结语

功能只是结果。真正的设计逻辑只有一条：把用户"想说却说不出口、想说却没人接、说完却留不下"的障碍，一个一个拆掉。上面每一个按钮，都是这条逻辑的落点。

AI 补上对手，人格补上身份，场景补上语境，报告补上成长，知乎补上更大的回响。
