# 产品说明计划书 · 交付说明

## 交付内容
针对「思辩星球 DebateSphere」编写了一份完整的**产品说明计划书**，覆盖用户明确要求的三条主线：核心思路、技术方案、与知乎生态的契合度。

**产出文件：**
- `产品说明计划书-思辩星球×知乎生态.docx` — 正式 Word 版（封面 + 7 章 + 附录，含 24 张表格），适合提交/分享
- `产品说明计划书-思辩星球×知乎生态.html` — 打印友好版（A4 排版），适合浏览器预览或导出 PDF

## 文档结构
| 章节 | 内容要点 |
|---|---|
| 摘要 | 一句话定位 + 三条主线概述 |
| 一、产品概述 | 定位、三类人格族群目标用户、v40.6 能力矩阵、90 天目标 |
| 二、核心思路 | 三道坎 → 三大设计支点（人格即身份 / 辩论即内容 / AI 即队友）、四大场景、产品闭环、差异化 |
| 三、技术方案 | 六层架构、技术栈、AI 能力层（知乎直答三档 + 四类 AI 角色 + 发言节奏引擎 + 风格学习）、人格引擎、知识引擎、实时对战、数据模型、安全、部署、取舍 |
| 四、知乎生态契合度 | 战略/能力/内容/用户四层契合、流量闭环、互补性、6 维自评（4.3/5）、深化合作设想 |
| 五~七 | 路线图、成功指标、风险与对策 |
| 附录 | 已落地知乎接口清单、术语表 |

## 关键决策
- **内容全部基于平台真实代码与本项目已有的知乎接入文档撰写**，未使用泛化描述——四大场景、PK 三档难度、逐句发言引擎、七维评分、6 类知乎 API 等均对应实际落地实现。
- 无 pandoc / .NET 环境，改用 `python-docx`（已装于托管 venv）直接生成，获得对中文字体、表格底纹、分页的完全控制。
- 内容模型与渲染分离：同一份 `CONTENT` 同时渲染 Word 与 HTML，保证两版内容一致。

## 后续可选项
- 若需提交给知乎生态合作方，可补充：团队介绍、财务/资源需求、更详细的分阶段 OKR。
- 如需 PDF，用浏览器打开 HTML → 打印 → 另存为 PDF 即可（CSS 已做打印适配）。
- 如需调整品牌色/封面，修改 `docs/gen_spec.py` 顶部的颜色常量后重跑即可。
